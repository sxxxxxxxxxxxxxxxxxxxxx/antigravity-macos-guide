Antigravity IDE / 2.0 (macOS) 深度配置与疑难解答指南

面向 Mac 用户的 Antigravity IDE 与 Antigravity 2.0 接入指南，重点解决版本识别、客户端不走系统代理、账号授权受阻、模型无法加载与首次验证等高频问题。

🚑 先看这里：遇到问题先看图对号入座

目前大家遇到的绝大多数问题，都是下面这四种报错。点图可放大对照；点下方蓝色链接跳到对应解决办法。

怎么对号（先看这几句）

• 账号没资格：先查地区与资格，再查年龄认证，不要先反复注入。

• unexpected issue / 网络超时：就是客户端没真正走通代理——请按 第三章网络配置 处理（Tun / Antify 等）。

• Further action / 扫码：登录阶段人机验证；年龄认证在「账号没资格」那条处理。不要狂扫十几次。

• 对话中断 / Agent terminated / 400 报错：100% 梯子 IP 被谷歌标记为受限地区，请按 Q3 换美/日纯净家宽 IP 并重开客户端。

• 桌面图标偏白多半是 2.0，偏黑多半是 IDE（看桌面快捷方式，不是软件内部主题）；发消息一直转圈：优先当网络未接管，不要先反复注入账号。
